# Форма авторизации

## Используемые технологии

**HTML** — структура страницы.
**CSS** — оформление страницы.
**TypeScript** — логика авторизации и проверка типов.
**Node.js** — среда выполнения JavaScript.
**npm** — установка и управление зависимостями проекта.
**nvm-windows** — управление версиями Node.js.
**Vite** — запуск проекта и сборка для публикации.
**ESLint** — проверка качества кода.
**Prettier** — автоматическое форматирование кода.
**Vitest** — автоматическое тестирование.

## Требования

Node.js версии 24.
npm.
Git.

Версия Node.js указана в файле `.nvmrc`.

## Установка зависимостей

Перейдите в папку `infra` и выполните:

```bash
npm install
```

## Запуск проекта

Для запуска локального сервера выполните:

```bash
npm run serve
```

После запуска откройте адрес, указанный в терминале Vite.

## Доступные команды

 `npm run serve` - Запуск локального сервера                             
 `npm run build` - Сборка проекта                                        
 `npm run lint`  - Проверка кода ESLint                                  
 `npm run lint:fix` - Автоматическое исправление некоторых замечаний ESLint 
 `npm run format` - Форматирование файлов Prettier                        
 `npm run test` - Запуск тестов Vitest                                  
 `npm run typecheck` - Проверка типов TypeScript                             

## Тестирование

Для запуска автоматических тестов выполните:

```bash
npm run test
```

Тесты проверяют:

правильность введённых учётных данных;
отклонение неправильной почты;
отклонение неправильного пароля;
независимость проверки почты от регистра букв.

## Сборка проекта

Для создания production-версии выполните:

```bash
npm run build
```

Готовая сборка помещается в папку `dist`.
