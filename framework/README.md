# Cow4 — React version

## Используемые технологии

React — создание интерфейса на основе компонентов.
TypeScript — статическая типизация.
Vite — сервер разработки и сборка.
Zustand — управление состоянием.
Vitest — автоматическое тестирование.
React Testing Library — тестирование компонентов.
ESLint — проверка качества кода.

## Структура проекта

`components/` — React-компоненты.
`store/` — хранилище состояния Zustand.
`tests/` — автоматические тесты.
`App.tsx` — корневой компонент приложения.
`App.css` и `index.css` — стили.

## Архитектурные решения

Интерфейс разделён на четыре компонента: `LoginForm`, `EmailInput`, `PasswordInput` и `AuthMessage`. Это упрощает поддержку и повторное использование частей интерфейса.

Zustand выбран для управления состоянием авторизации. Он позволяет хранить общие данные и действия отдельно от пользовательского интерфейса.

Для тестирования используются Vitest и React Testing Library. Тесты проверяют отображение компонентов, обработку ввода и авторизацию.

## Установка и запуск

Установка зависимостей:

```bash
npm install
```

Запуск сервера разработки:

```bash
npm run dev
```

Сборка:

```bash
npm run build
```

Запуск тестов:

```bash
npm run test
```

Проверка кода:

```bash
npm run lint
```

## Архитектурные решения

## Выбор Vite

Для сборки проекта и запуска сервера разработки выбран Vite.

Причины выбора:

1. быстрая загрузка проекта и запуск сервера разработки;

2. поддержка React и TypeScript;

3. быстрая обработка изменений благодаря Hot Module Replacement;

4. простая конфигурация;

5. возможность собирать проект для production.

6. Vite позволяет не настраивать сборку вручную и сосредоточиться на разработке приложения.

## Выбор Zustand

Для управления состоянием приложения выбран Zustand.

В качестве альтернативы рассматривался Redux. Однако для небольшого приложения авторизации Redux может оказаться избыточным: он требует больше шаблонного кода и дополнительной настройки.

## Zustand выбран по следующим причинам:

1. простая настройка хранилища;

2. небольшой объём кода;

3. удобное использование в React-компонентах;

4. возможность хранить состояние и функции изменения состояния в одном месте.

5. ю В проекте Zustand используется для хранения сообщений авторизации, сохранённой почты и функций входа и регистрации.

## Выбор Vitest и React Testing Library

Для тестирования выбраны Vitest и React Testing Library.

Vitest выбран потому, что:

1. хорошо интегрируется с Vite;

2. использует знакомый синтаксис тестов;

3. поддерживает быстрый запуск тестов;

4. позволяет проверять TypeScript и React-приложения.

5. React Testing Library используется для тестирования компонентов с точки зрения пользователя.

6. Вместо проверки внутренней реализации компонентов проверяется их поведение: отображение элементов, ввод данных и реакция на действия пользователя.

7. Дополнительно используется user-event, который позволяет имитировать действия пользователя, например ввод текста и нажатие кнопок.
